# story-of-the-day-evaluation-materials

This repository contains the supplementary evaluation materials for the manuscript:

**Story of the Day: A Prototype for Language-Model-Based Multimodal Daily Story Generation from Structured Daily-Life Context**

The repository provides supporting materials for the evaluation reported in the manuscript, including the complete LLM input structure, prompt templates, reconstructed ground-truth references, generated model outputs, criterion-level evaluation scores, and Story Alignment Score (SAS) values.

## Supplementary Material

The complete supplementary material is available here:

[**story-of-the-day-supplementary-material.docx**](https://github.com/Ishan1521/story-of-the-day-evaluation-materials/blob/main/story-of-the-day-supplementary-material.docx)

The document contains:

- the final structured LLM input format;
- three prompt templates;
- few-shot examples;
- reconstructed ground-truth references for three real-life scenarios;
- generated outputs from the evaluated language models; and
- Story Alignment Score (SAS) values.

## How to Open the File

The supplementary material is provided as a Microsoft Word (`.docx`) file. GitHub may not display the complete document directly in the browser.

To view the file:

1. Open the supplementary material using the link above.
2. Click **Download raw file** or the download icon.
3. Open the downloaded file using Microsoft Word, LibreOffice Writer, Google Docs, or another compatible `.docx` viewer.

## Evaluation Setup

The evaluation includes three real-life daily-story scenarios, three prompt designs, and six language models.

For each model--prompt--scenario combination, the supplementary material provides the generated story together with the corresponding criterion-level evaluation and Story Alignment Score (SAS).

## Repository Purpose

This repository provides detailed supporting material that could not be included in full in the main manuscript because of space limitations. It allows readers and reviewers to inspect the complete prompting setup, scenario-specific ground-truth references, generated outputs, and scoring results.
